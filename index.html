THE RITUAL

  1. PICK A CARD

    Every OnlyActions repository is one card in the deck, carrying its real, measured power stats.

  2. INSPECT IT

    Click any card: the inspector opens with its full lore, topics and every link that exists — no dead ends.

  3. ONE CLICK, YOU'RE THERE

    Repo, living report, action runs, releases, subscription files — each is a single click from the card you're holding.

The whole deck is real text — your browser's find-in-page (Ctrl / Cmd + F) works across every card.

Grow the deck

  1. 1Ship a new repository under onlyactions.
  2. 2Bind the deck: add one card block to js/data.js in this repo — name, lore, real stats, links.
  3. 3Push to main. GitHub Pages rebinds the deck — a new card joins the field. No build step.
